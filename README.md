# Benaya Law Attorney — Website

Next.js 16 (App Router, Server Components) + Payload CMS 3 + Tailwind CSS 4.
Architecture and decisions: `../ANALISIS-IMPLEMENTASI-NEXTJS.md` and `../ANALISIS-TECH-STACK.md`.

## Quick start (local)

```bash
pnpm install
cp .env.example .env      # fill PAYLOAD_SECRET + SEED_ADMIN_EMAIL / SEED_ADMIN_PASSWORD
pnpm seed                 # creates the SQLite DB, the admin account and placeholder content
pnpm dev                  # http://localhost:3000  ·  CMS: http://localhost:3000/admin
```

Without `DATABASE_URL` the app uses a local SQLite file (`bla.db`), so no database server is needed.

## Scripts

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server |
| `pnpm build` / `pnpm start` | Production build / server (run `pnpm seed` first on a fresh DB) |
| `pnpm typecheck` / `pnpm lint` | TypeScript / ESLint |
| `pnpm seed` | Idempotent seed (admin + placeholder content) |
| `pnpm generate:types` | Regenerate `src/payload-types.ts` after changing collections |

## Where things live

| Path | Contents |
|---|---|
| `src/app/(frontend)` | Public site: layout (SEO, no-flash theme script), home page, `/artikel/[slug]`, Server Action |
| `src/app/(payload)` | CMS dashboard + REST/GraphQL (generated by Payload — don't edit) |
| `src/components/sections` | One Server Component per homepage section |
| `src/components/*-switch.tsx`, `consultation-form.tsx`, `mobile-menu.tsx`, `map-facade.tsx` | The only client components |
| `src/collections`, `src/globals` | CMS schema |
| `src/access/roles.ts` | RBAC (admin, partner, editor, lawyer) |
| `src/jobs/sendLeadEmail.ts` | Lead notification job (Resend; logs when no API key) |
| `src/app/(frontend)/globals.css` | Theme tokens, section tones (`data-tl` / `data-td`), dimensional switches |

## Production checklist

1. **Database** — set `DATABASE_URL=postgres://…`, then `pnpm payload migrate:create` (once) and `pnpm payload migrate` on deploy.
   Region is the client's call (UU PDP): Singapore (Neon/Supabase) or Jakarta (AWS `ap-southeast-3`).
2. **Secrets** — `PAYLOAD_SECRET` (long random string), `NEXT_PUBLIC_SITE_URL`.
3. **Email** — `RESEND_API_KEY`, `LEAD_EMAIL_TO`, `LEAD_EMAIL_FROM` (verified domain).
4. **Jobs** — on a long-running server the queue runs every minute automatically. On serverless, call `/api/payload-jobs/run` from a platform cron.
5. **Rate limit** — in-memory (single server). For serverless / multiple instances switch `src/lib/rate-limit.ts` to Upstash.
6. **Media** — local disk by default; add a storage adapter (Cloudflare R2 / S3) for multi-instance hosting.
7. **Admin** — protect `/admin` with Cloudflare Access or an IP allowlist.
8. **Content** — replace every placeholder (lawyer names & photos, testimonials, articles, stats) with verified data before going live.
